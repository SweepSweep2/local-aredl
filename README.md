# Local AREDL

**NOTE: This site is still undergoing changes to the UI and new features are going to be added. I'm not fully done with this.**

---

[Local AREDL]("https://sweepsweep2.github.io/local-aredl/") is a spin-off of [AREDL]("https://aredl.net") that allows you to keep track of your AREDL points "locally", instead of having to depend on your records being accepted.

This website was created for people who are unable to record completions (no mic, bad pc, etc.) or people who don't want to wait in a queue to be able to track their AREDL points, progress, and completed demons.

Keep in mind that this website should not be used 100% in replacement to AREDL!!! Please support the staff and helpers of AREDL who work hard to make everything possible.
