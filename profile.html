How to Get Your AREDL API Key

Go to AREDL, and log in to your account. Then, click your account profile picture at the top right, and click Settings. Then, scroll down to the bottom, where the Developer Setting section rests. Inside the API Key lifetime text box, enter in 300. (this will make the API key last 5 minutes) Then, click Create and copy API Key to clipboard, and then input your API key into the input box.

If you are worried that this website will steal your API key, you can either look at the source code (CTRL + U or GitHub). There will be comments guiding you through what the website does with your API key, and proof that it only goes to AREDL.
